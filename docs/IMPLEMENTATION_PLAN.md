## 不变约束

问题绑定具体版本，冻结后不能换规则；结果属于问题版本。所有预登记模型任务保留，包括失败/取消/超时。未知调用不视作零费用或可安全盲重试。预测、判定与评分只追加。模型、入场审核、裁决与时间验证使用分离身份；两个账号不自动证明两名独立审核者。

## 已关闭的工程缺口

- LIVE 在首次尝试/批次前固定 FORMAL 或 DIAGNOSTIC；联调不能封存为正式成绩，旧无政策记录不可追溯升级。
- CALENDAR/TARGET_STATUS 保存来源材料、哈希、用途、服务器时间和身份；独立确认检查 ID 与事件簇，元数据进入预登记承诺。
- 正式领取与 provider request 数据库写入均检查时间资格、有效期、暂停、已知/不确定状态和时间余量，不仅依赖新 CLI。
- 相关 BLS 序列按发布族与 UTC 时间分簇；未找到答案只说明所检查快照，不自动证明全网未知。
- 默认本机只读部署、分离身份与私有配置；模型 profile 显式开启。有界 operator 复用既有恢复/预算/封存账本，不建平行控制器。
- 真实 Docker 安装、重复 bootstrap、数据库中断恢复、同集群新库还原/指纹比较、Chromium 测试通过。
- 源码、wheel、干净环境已安装包的50个文件与13个迁移核验通过；配置预检不会联网、付费或泄露值/路径。

当前仍为二元与分箱题、固定证据赛制 A、一个实验一批初始预测。连续 CRPS、自由检索赛制、预测更新排名、完整研究编辑器和公开竞争产品尚未完成。

## 接下来按依赖执行

### A. 收束发布基线
PR #9 按普通 merge 汇合叠加历史，固定2.0.1.dev1，并核对 main 内容 tree 与自身完整 CI。旧迁移保持不变，不强推，不用工程合并关闭 #5/#7。具体证据见 [本版报告](../reports/PREVIEW_BASELINE_VALIDATION.md)。

### B. 用户环境受控试运行
按 [真实验收交接](LIVE_ACCEPTANCE_HANDOFF.md) 落实目标宿主和安全执行入口，验证权限/挂载、凭证隔离、健康检查、进程监督与备份恢复。补外部告警接收器、跨主机身份/数据恢复、外部网络故障演练。日志提醒不等于通知送达，同集群还原不等于 RPO/RTO 证明。

### C. 三家模型与外部时间服务
安全配置真实凭证、型号与预算。先 DIAGNOSTIC 核查请求/usage/拒绝/截断/费用，再登记全新的 FORMAL 实验。核实生产 TSA/CA/policy/精度与撤销策略，真实取得并独立验证两个批次时间证明。测试 CA 不得升级为生产信任根，未知费用不得归零。#5/#7 以证据关闭。

### D. 首批真实前瞻
少数获准官方宏观/政策模板，核查目标、日历、资料真实性、首次值/修订值与事件相关性。事前冻结完整任务，现实结果发布后盲化确认和独立复算。未来结果未发生时保持待定，历史回放/合成事件不充数。一个成功实验不证明长期优势。

### E. 专业研究与公开档案
受控研究工作流（授权检索、历史基准、反证、情景、概率和可追溯报告）与固定证据赛制分开评价。建设公开实验登记和只读模型档案，防止整批选择性披露，保留版本、失败、成本与样本限制；公开原文须有许可。研究能力与预测评分分别验收。
