## 不变的实施约束

问题绑定具体版本，冻结后不能换规则；结果属于问题版本而不是每个模型。所有预登记模型任务均保留，包括失败/取消/超时。未知调用结果不视作零费用或可安全盲重试。只追加历史预测、判定和评分。独立模型、裁决人和时间验证人使用不同的实际身份。

## 已完成的工程连接

1. P0-01问题/许可 → P0-02完整实验与任务。
2. P0-03统一冻结证据 → 受控请求、观测和候选分布。
3. P0-04完整REGISTRATION与FORECAST批次 → 精确字节/nonce/Merkle承诺 → RFC3161请求、独立验证、完整导出；缺失预测仍在清单。
4. P0-05原始结果证据 → 独立提案/确认 → 全模型共享结果 → 固定算法版本评分。补录版本改变结果选用时STALE_EVIDENCE暂停新计分，不覆盖历史。
5. P0-06预登记比较族 → 事件簇Bootstrap/符号翻转/Holm → 完整覆盖率和分层；测试和无时间资格的分数不混入正式结果。
6. P0-07有界worker、独立恢复命令、BLS精确期间候选与内部HTTP运行台。集成测试使用明确标注的合成事件与本地测试CA。

当前二元和分箱题，固定赛制A，一个实验一个初始预测批次。连续CRPS、自由搜索赛制、预测更新排名、完整研究编辑器和复杂图谱均未声称完成。

## 下一实际交付关卡：不是再堆四批功能

按Issue #5/#7提供环境与证据，在安全部署中完成：

- 三家真实供应商请求、错误路径、费用核对；指定真实可用模型和预算。
- 独立核实TSA/CA/政策/精度，实际获得预登记与最终预测的事前证明；原始回包可独立重验。
- 少数已授权官方题源，人工核查真实日历、已知答案和原始发布版本，开展结果尚未知的预测。结果发布后双人盲审与正式计分。
- 常驻进程监督/调度、备份还原、预算告警、限流和真实网络中断恢复；未部署这些不能宣称无人值守。
- 浏览器实机验收、生产身份和访问安全、公开导出授权审查。

工程模拟可以现在验收，未来事件尚未发生的结果不能现在造出来；历史回放不得冒充真实前瞻成绩。缺少凭证不回退模拟成功。工作台默认本机，不直接开放公网。
