文档：`docs/P0_01_DATABASE.md`、`docs/adr/011-question-persistence.md`、`reports/P0_01_VALIDATION.md`。

## P0-02：实验与任务账本（下一批）
预登记全量题集/参赛配置/时点/预算/回退规则。实现事务 outbox、任务唯一键、lease/fencing、失败恢复和成本预留。
任务外键必须绑定具体 question_versions.id；不得运行时悄悄切换为新版本。
区分正式任务、执行 attempt 与外部调用；未知调用结果不当作零费用或安全重试。
验收：并发重复运行不产生多个正式初始预测；单题失败不拖停其他题；所有失败在分母中；过期 worker 不得提交覆盖新 worker。
先用显式模拟执行器验证任务恢复，不把它称为真实模型接入；模型接入在 P0-03 验收。

## P0-03：证据包与真实模型
统一证据包哈希、工具禁用/许可门控。分别实现 OpenAI、Anthropic、Google 的 Provider Adapter。
每次数据处理重新检查许可，作者/审核账号与模型运行账号分离。
验收：每家一组真实请求、超时、限流、格式失败及成本记录；模型 ID 和参数可导出。密钥缺失明确 BLOCKED。

## P0-04：外部时间与完整批次
实现安全规范化编码、随机 nonce、Merkle 批次、RFC3161 请求/验证和 OTS 独立状态。
验收：第三方只凭导出可验证内容与截止资格；故障无假成功；篡改、遗漏、复制提交被发现。OTS 未确认不冒充已确认。

## P0-05：独立裁决与评分
结果证据采集、盲化审核权限、VOID/争议原因、版本化重算、基准和失败回退。
补齐 P0-01 跨阶段验收：FIRST_RELEASE / LATEST_AT_RESOLUTION_DEADLINE 对真实数据版本选择正确；问题版本级结果由全部模型共享。
验收：裁决者查询不到概率；结果变更后新旧评分可追溯；手算与独立实现一致。

## P0-06：统计与内部工作台
实现配对及聚类 Bootstrap、Holm、规划用样本量估算、覆盖率/失败率/成本和初始/更新分榜。
验收：固定种子重现；同簇问题不拆散；无混合赛制排名；样本不足显示暂定。动态方差估计不能用于未声明的可选停止。

## P0-07：真实前瞻小批运行
启用少数授权官方发布模板；自动审查已知答案/早期结果泄漏；记录全部任务。连续运行与故障恢复验证。
验收：实际外部时间证明、真实结果及评分闭环可第三方复核。历史回放不计真实成绩；任务量与统计证据分开。
