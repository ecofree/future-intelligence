## 不变约束

问题绑定具体版本，冻结后不能换规则；结果属于问题版本。所有预登记模型任务保留，包括失败/取消/超时。未知外部调用不视作零费用或可安全盲重试。预测、判定与评分只追加。模型、入场审核、结果裁决和时间验证使用分离身份；两个账号不自动证明两名独立审核者。

## 本批关闭的工程缺口

- LIVE 在首次尝试/批次前显式固定 FORMAL 或 DIAGNOSTIC；联调不能封存为正式成绩，旧无政策记录不可追溯升级。
- CALENDAR/TARGET_STATUS 保存来源材料、哈希、用途、服务器时间和身份；独立确认检查 ID 与事件簇，元数据进入预登记承诺。
- 正式领取与 provider request 的数据库写入均检查时间资格、检查有效期、暂停、已知/不确定状态和时间余量，不只在新 CLI 上检查。
- 相关 BLS 序列按发布族和 UTC 时间分簇；没有找到答案只说明所检查快照，不是自动证明全网未知。
- 默认本机只读部署，独立身份与私有配置；模型 profile 显式开启。有界 operator 复用现有恢复/预算/封存账本，不建平行控制器。
- 真实 Docker 安装、重复 bootstrap、数据库中断恢复、同集群新库还原/内容指纹比较、真实 Chromium 测试通过。

当前仍为二元与分箱题、固定证据赛制 A、一个实验一批初始预测。连续 CRPS、自由检索赛制、预测更新排名、完整研究编辑器和公开竞争产品尚未完成。

## 接下来按依赖执行

### A. 收束发布基线
审查叠加 PR、处理主分支合并、固定工程预览版本并从干净环境复验。已应用迁移保持不变。主分支合并不能代替真实服务验收。

### B. 用户环境的受控试运行
在目标宿主验证实际权限与挂载、凭证隔离、健康检查、进程监督和备份恢复。补外部告警接收器、跨主机身份/数据恢复及外部网络故障演练。当前日志提醒不等于通知送达，同集群恢复不等于 RPO/RTO 证明。

### C. 三家模型与外部时间服务
安全配置真实凭证、型号与预算。先 DIAGNOSTIC 核查供应商请求/usage/拒绝/截断/费用，再登记全新的 FORMAL 实验。核实生产 TSA/CA/policy/精度与撤销策略，真实取得并独立验证两个批次时间证明。测试 CA 不得升级为生产信任根，未知费用不得归零。#5/#7 以证据关闭。

### D. 首批真实前瞻
少数获准的官方宏观/政策模板，核查目标、发布日历、资料真实性、首次值/修订值与事件相关性。事前冻结并保留完整任务，现实结果发布后盲化确认和独立复算。未来结果未发生时保持待定，历史回放/合成事件不充数。一个成功实验也不能证明模型长期更强。

### E. 专业研究与公开档案
受控研究工作流（授权检索、历史基准、反证、情景、概率和可追溯报告），与固定证据赛制分开评价。建设公开实验登记与只读模型档案，防止整批选择性披露，保留版本、失败、成本与样本限制；公开原文须有许可。研究能力和预测评分分别验收。
