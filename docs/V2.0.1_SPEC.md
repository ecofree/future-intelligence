# Future Intelligence V2.0.1 工程基线

日期：2026-11-16。状态：**初始化设计基线冻结；实现尚未通过 MVP 验收**。

## 1. 输入与范围

依据：当前对话已确定的 V2 产品方案、Grok 评估及 `sources.md`、`sample_size_sim.py`。原始上传文件按字节保留在本地初始化包；公开仓库只保留 `reference/manifest.json` 中的 SHA-256 清单，不公开附件正文。本文件是工程决策，不把原报告的外部陈述自动升级为核实事实。

定位：专业未来研究系统，保留多模型公开竞争及独立成绩档案。外部基准提供独立比较，自有题库验证专业研究价值。先内部研究，按预登记披露策略对外公布可验证记录。

首期启用宏观与政策；全球市场、地缘、科技、社会为扩展分类，**不是六套部署**。快速反馈与战略研究共享证据和预测设施，但题集、成本、模型评估分开。60/40 资源比例是可调整起点，不是得分权重。

## 2. 实现范围与验收分离

初始化代码只含评分、内容承诺/证明和 Provider 契约，不声称完整 MVP。

MVP 必须形成：问题版本 → 审题 → 实验预登记 → 冻结证据包 → 模型独立调用 → 预测提交及外部时间证明 → 独立结果判定 → 评分 → 完整批次导出。

初期只实现二元和分箱数值；多选及时间到事件保留类型规划，后续实现。三家供应商首先接 OpenAI / Anthropic / Google，型号和预算外部配置，完成标准是每家真实请求和失败处理通过验收，而非类名存在。

## 3. 状态与核心不变量

分开存储四类生命周期，不用一个混合状态列管理全部对象。

- 问题版本：DRAFT → REVIEWED → FROZEN → CLOSED。
- 任务：QUEUED → RUNNING → SUCCEEDED / FAILED / TIMED_OUT / CANCELLED。
- 时间证明：NOT_REQUESTED → PENDING → VERIFIED / FAILED；失败重试创建独立 attempt。
- 结果：PENDING → PROPOSED → CONFIRMED；可进入 DISPUTED 或 VOID。

所有终态变化留事件日志。问题超过有效期限仍未拿到结果时不是自动 FALSE。只有事先规则满足才能结算。结果修订产生新 resolution 版本，旧结果和旧评分不删除。

冻结对象包括问题、规则、数据口径、基准、参赛名单、快照、预算、重试/失败规则和披露规则。数据库管理员仍可能改库，故追加权限和哈希不是绝对防篡改，也不是可信时间证明。

## 4. 数据实体与所有权

`sources / source_permissions`：许可、期限、用途、许可证证据及撤销状态。

`documents / evidence_snapshots`：原始版本及实际送入模型的字节包，分别存发布时间、首次观测时间、采集时间和内容哈希。

`questions / question_versions`：事件定义、事件簇、时区、预测截止、实际结果最早可知时刻、目标区间、判定及修订口径、预设兜底源。

`experiments / entries / expected_tasks`：赛制、模型配置哈希、相同题集及所有预登记任务。失败任务保留，不从分母消失。

`forecast_runs / provider_calls / forecasts`：运行尝试、供应商原始响应及可公开摘要；锁定预测为追加记录。一次正式任务仅一份初始有效提交，重试是 attempt 不是重复参赛。

`commitment_batches / anchor_attempts`：完整清单、Merkle 根、证明文件、外部签名与校验结果。时间服务原始响应和验证器版本保留。

`resolutions / score_runs / scores`：结果绑定**问题版本**；所有模型预测共享该结果。评分绑定预测版本、结果版本与算法版本。

`budget_reservations / audit_events`：先原子预留预算，再调用；实际费用结算，未知费用标记未知，不能默认为零。

## 5. 赛制与证据时间

赛制 A：同一冻结背景材料、无联网、无其他模型答案。称“统一证据包模型赛”，不声称与外部榜单的裸模型条件完全相同。

赛制 B：完整受控研究流程，有检索/反证/预测，预算和工具白名单预登记。其他参赛模型输出隔离；单模型研究结果不暗中共享给竞争模型。

已知正式结果的题不能纳入前瞻测试。正式证据须在截止前真实获取；仅网页标注早期日期不足以证明可用。外部模型未知训练数据、事后模型或历史回测不能声称无泄漏；只能标探索性回放，绝不计入真实前瞻成绩。

## 6. 锁定、可验证披露和隐私

首选在截止前得到已验证的 RFC3161 令牌；OpenTimestamps 为独立后续锚定层。未取得合格时间证明的提交标记 `UNVERIFIED_TIME`，不悄悄升格为公开正式成绩。

登记完整任务清单及每任务唯一预测承诺，防止预先承诺所有答案后挑选成功版本。每日根只能证明该时刻之前已有内容，**不能倒推为当天任意更早截止前的证明**。以外部证明时间加预先登记的精度/误差规则评估资格。

私密预测承诺加每条独立随机 nonce（至少 256 位），防止小概率空间被枚举。公开元清单与未披露数量；敏感档案不允许随结果好坏选择披露。无法公开的记录须走预登记独立审计机制，不能把不可审计子集包装成完全公开成绩。

当前代码只做内容承诺及 Merkle 完整性，没有 TSA/OTS 请求或可信时间验收。

## 7. 评分及统计

二元主指标 Brier；Log Loss 为诊断。**本初始化实现不裁剪原始概率**：错误的 0/1 预测产生无穷 Log Loss，不用静默裁剪美化。生产若限制概率范围，必须在实验前冻结并对所有系统一致执行。

分箱数值用归一化 RPS：累积概率误差平方和除以 K−1；固定边界、含端点规则和分箱哈希，不能跨不同分箱直接排总榜。连续 CRPS 后续实现。

比较采用同题配对、独立事件簇聚类重采样、固定种子与算法版本；报告样本数、簇数、覆盖率、失败率、分领域和时距。多重比较预设主比较、其余用 Holm。不能把“不显著”写成“相等”或“已经打平”。

样本量脚本是给定假设下估计方差再代入近似公式，不是完整功效验证。不得把 150/200/1000 题当通用证明门槛。先用试点实测配对方差与簇结构，再冻结后续正式检验样本计划；不允许边看结果边随意停止。

缺失预测必须有预登记处理：覆盖率单独报告；完整共同样本只能作条件性比较，不能把成功子集分数当整体可靠性。生产主指标可采用预登记基线回退，回退任务必须显式披露。

## 8. 工程架构和安全

模块化单体：Python/FastAPI，PostgreSQL 为业务真相源，独立 worker，对象存储放证据。前端后续 Next.js。当前离线计算模块不需要数据库、外部服务或第三方库。

写任务幂等键唯一，outbox 与业务变更同事务；worker lease、到期重领和 fencing token；网络请求重复不等于可保证只计费一次，保留 uncertain attempt 并对账。应用角色禁止更新已锁定表，独立裁决角色不可查询预测值。

最小内部 API：questions/version/freeze、experiments/register、runs/start、forecasts/commit、anchors/status、resolutions/propose/confirm、scores/recompute、exports/batch。API 不接受用户伪造 locked_at。

外部内容不能下发工具指令；防 SSRF、限制下载大小/类型、域名与目标 IP 验证、密钥隔离、成本硬上限。许可检查默认拒绝，公开来源也不能一律推定为可商用。

部署和收费地区尚未确认；默认内部使用不等于获得法律豁免。大陆生成式服务、内容标识、投资咨询、新闻服务和跨境数据均须做具体适用性审查，当前不提供确定法律结论。
