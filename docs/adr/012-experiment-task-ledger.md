# ADR-012：预登记任务、费用未知与租约隔离

日期：2026-11-16。状态：P0-02 实施；以验收报告记录实际运行范围。

1. 实验冻结具体问题版本和模型配置，并原子登记完整笛卡尔积任务；任务与执行尝试分开，失败不删。
2. 执行器用独立数据库 LOGIN 绑定单参赛配置；业务参数不接受伪造 actor、fence 或时间。operator 为受信任控制面。
3. 采用 PostgreSQL 短事务、统一预算→任务锁顺序、租约/fencing 和事务 outbox；不引入新 broker/控制器。所有权变更只影响数据库提交权限，不假定能终止已发出的网络请求。
4. 调用开始标记必须在联网前提交；未开始的租约超时可安全重试，已开始而结果未知的尝试必须挂账核对。费用未知使用 NULL/HELD_UNKNOWN，不能映射为零。
5. 预算是预留准入控制；实际超支照实记录，并阻止新领取及未派发任务开始。对已经在途请求不保证账单硬上限，P0-03 必须进一步约束供应商请求。
6. 候选结果与可计分预测分离；唯一回执防止重试覆盖，结果不具有外部可信时间资格。FIXTURE 执行器不承接 LIVE 实验。
7. 首版只实现赛制 A 与 REPORT_MISSING。基线、披露策略预登记不等于评分或公开导出已实现。
8. 持续调度部署、真实供应商、证据包、可信外部时间和结果判定属于后续关卡，不以本批数据库测试通过冒充完整 MVP。
