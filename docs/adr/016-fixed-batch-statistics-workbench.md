# ADR-016：预登记统计与最小内部工作台

状态：工程实现。

在 REGISTRATION 封存比较对、随机种子、重采样次数、显著性水平、簇阈值和固定批次停止规则。重复/反向比较对拒绝。同问题配对，按事件簇整体 Bootstrap；符号翻转检验的独立性与对称性假设必须披露。Holm 对整族比较校正；样本量估算只供规划，不允许据此选择性停止。

按赛制、运行类型、领域、轨道、题型、分箱与单位分层，不混合不同量纲评分。当前仅初始预测实验；预测更新需另行登记，未声称完成所有长期统计或校准图表。

首版采用 FastAPI 同源 HTML + 小型 JS 内部看板，而不是另起 Next.js 工程。这样先交付可操作的真实数据库路径，保留后续前端替换接口。仅本机监听，显式 Bearer token 对应独立数据库角色；裁决角色不能读预测和成绩。不提供付费模型触发 HTTP 入口。

当前页面为运行数据表和评分档案，不是成熟研究编辑平台；远程上线需额外 TLS/身份与会话/速率限制评审。浏览器实机访问验收与 HTTP TestClient 是两项不同证据。
