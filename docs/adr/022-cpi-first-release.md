# ADR-022：2026 年 11 月 CPI 首发结算合同

日期：2026-11-18。合同标识：`fi.cpi-2026m11.first-release.v2`。v2 补齐两个截止的精确时刻与包含规则、完整条款绑定要求；已引用 v1 的冻结对象保持原样，不能凭文档更新改变它们。

状态：新问题版本的候选合同及离线算术已实现；**没有已登记 FORMAL，也没有首发结果或时间证明**。这是后续新版本的规则，不回写任何已冻结题目、实验或账本。问题措辞、证据或输入改变后须先另建 DIAGNOSTIC。

## 1. 目标与权威单元格

目标是 BLS 2026 年 11 月 CPI 新闻稿中 **Table 1 → All items → Unadjusted indexes → Nov. 2026** 的指数 `V`：CPI-U、U.S. city average、未季调、1982–84=100、序列 `CUUR0000SA0`，按新闻稿刊出的三位小数读取。不能换成核心 CPI、季调值、环比或刊出的一位小数同比。

主要载体是该参考月官方 HTML 新闻稿及其同一版本归档；同批官方 PDF 可作为佐证，但要证实版本对应。当前时序 API 只用于交叉核对，不能单凭最新返回值证明首次刊出。若 HTML 与对应 PDF 在目标单元格发生实质冲突，不能默选有利值，进入争议流程。

每份证据保留原始文档字节、来源 URL、抓取时间、声称的发布时间、内容 SHA256、参考月及行列定位；独立审查其发布版本。SHA256 和本地抓取时间本身不是可信外部时间证明。不得把未发布的未来归档 URL 当作已取得证据。

## 2. 固定常数与精确结果

| 项目 | 固定值 | 官方归档定位 |
|---|---:|---|
| 二元题比较基准 | 337.511 | [2026-11-10 新闻稿](https://www.bls.gov/news.release/archives/cpi_11102026.htm)，Table 1 / All items / Oct. 2026 未季调指数 |
| 同比计算分母 | 324.122 | [2025-12-18 新闻稿](https://www.bls.gov/news.release/archives/cpi_12182025.htm)，Table 1 / All items / Nov. 2025 未季调指数 |

两项值于 2026-11-18 独立查看上述官方归档核对。正式登记前取得获准原始快照并冻结其哈希；若发现实质差异，停止登记、查明版本，再建立新的问题/诊断，不改旧常数来适配结果。

二元题：`V >= 337.511` 为 Yes，数据库结果 `value_text="1"`；否则为 No，`value_text="0"`。等号归 Yes。

五类别题按 `Y = 100 × (V − 324.122) / 324.122` 计算同比百分数：

| 类别下标 | 精确区间 |
|---|---|
| 0 | Y < 3.0 |
| 1 | 3.0 ≤ Y < 3.5 |
| 2 | 3.5 ≤ Y < 4.0 |
| 3 | 4.0 ≤ Y < 4.5 |
| 4 | Y ≥ 4.5 |

分类前不舍入。以整数千分位构造精确分数，不能用浮点近似或 BLS 刊出的一位小数同比决定类别。两题属于同一个发布事件簇，不能当成两个独立宏观事件来声称样本量或模型优势。

## 3. 首次刊出与官方错误更正

本合同选择 **FIRST_PRINTED_LOCKED**，对应现有数据库的 `FIRST_RELEASE` 政策：锁定该参考月目标单元格第一次正式刊出的数值。若 BLS 随后更正采集、编制或刊印错误，追加更正证据、实际更正发布时间及对两题结果的影响说明，**不替换本实验的主结算数值或主评分**。冻结的两项历史常数也不随之后的更正悄悄变化。

这是实验的事前规则选择，不是声称 BLS 永远不更正数据。BLS [CPI Handbook 的 Correction and revision policies](https://www.bls.gov/opub/hom/cpi/presentation.htm) 明确区分不做迟到数据的常规修订与罕见错误更正，也说明可能暂缓刊出或暂时撤下错误值。

自身的抄录、计算或证据归属错误不属于 BLS 的后续更正。若原证据值正确、仅裁决或评分处理有错，可走既有追加式 resolution/score 修订，保留原因与新旧记录。若错误数值已经写入不可变的 `outcome_evidence`，现接口没有证据替代机制；立即进入 DISPUTED、暂停有效评分并保留错误，不宣称追加普通 revision 就能更正。不得改旧证据、伪造更早发布时间或把内部错误伪装成官方修订。未经合法、可审计的修复不能再标 RESOLVED；到结算截止仍未解决则 VOID。裁决人员不得查看预测概率来选择结果版本。

后续官方更正原文及影响说明保存在原始证据/审核档案。只有符合已冻结观察窗口与来源许可的更正才能另行登记为 `outcome_evidence`；结算截止后公布的更正只留档披露，不为了录入而放宽数据库时间窗口。

数据库 `selected_release` 只会从**已登记证据**中选最早值，不能证明互联网中的真实首次刊出。不得给更正稿回填原计划发布时间或把后来页面伪装为首发；仅登记一个晚期版本并通过 SQL 检查也不构成首发验收。

## 4. 缺失、推迟、冲突与截止

首次预定新闻稿若目标单元格为空白、破折号或被暂缓刊出，保持 PENDING；采用结算截止前该参考月目标单元格**首次正式刊出的非缺失数值**。推迟不等于二元 No，也不直接归最低类别。首次数值必须仍可对应本合同的官方新闻稿/归档单元格，不能临时换用另一指标。

若无法确定首发版本、只能取得后来更正的值、或同批官方版本实质冲突，进入 DISPUTED，保留证据与独立审查记录；到预登记结算截止仍无法可靠解决则 VOID，不猜值、不用当前 API 值补造首发。

PENDING/DISPUTED/VOID 由冻结规则及独立操作执行，不是自动定时器。VOID 使用既有 proposal/confirm 和新 score run，旧记录保留；不声称数据库已有不可再追加裁决的永久终局锁。数据库窗口限制检查官方发布时间，不能将它与抓取时间、入库时间或合同的裁决截止混淆。

官方 [CPI 日历](https://www.bls.gov/schedule/news_release/cpi.htm) 与 2026 年 10 月新闻稿均列出 2026 年 11 月 CPI 预计 **2026-12-10 08:30 America/New_York = 13:30 UTC = 21:30 Asia/Shanghai** 公布。实际首次可知时间仍须独立核验。若登记前官方日历改变，重新冻结相应新版本；登记后不得通过延长预测截止来挽救迟到预测。

2026-11-18 最新交接已明确，未来新问题版本采用以下边界：

| 边界 | Asia/Shanghai | UTC | 包含规则 |
|---|---|---|---|
| 预测截止 | 2026-12-10 21:30:00 | 2026-12-10T13:30:00Z | 预测与证明不确定性上界均须严格早于此时刻 |
| 结果最早发布时间 | 2026-12-10 21:30:00 | 2026-12-10T13:30:00Z | 包含此时刻 |
| 结算截止 | 2027-01-31 23:59:59 | 2027-01-31T15:59:59Z | 包含此时刻；不自动延伸至下一秒 |

预测窗口不含末端，因此预测截止与结果最早发布时间可以相等。新前向迁移 0018 明确这个语义，并把证明资格改为严格 `<`，见 [ADR-023](023-controlled-retest-boundaries.md)。Sol 历史题目的 `outcome_not_before=2026-12-10T13:30:00.000001Z` 会排除真实整点发布；保留该冻结值和缺陷，不把官方 `published_at` 人为加微秒来迁就它。下一轮建立新题与新诊断。

正式登记冻结完整条款：把本合同的目标、常数、区间、首发更正策略、缺失/延后、版本冲突、内部错误、VOID 和截止写进实际 `resolution_rule`，或用冻结对象所引用的完整规则字节哈希绑定。合同标识/ADR 链接单独出现不足以证明所有条款已冻结。完整私有导出须可重算这些哈希。

## 5. 离线转换与人工审核衔接

入口：

```text
python -m future_intelligence.delivery.cpi --index <独立核验后的三位小数指数>
```

输入必须为正数、规范三位小数字符串。输出保留原指数、固定常数、精确同比分子/分母、二元值、五类别下标及候选状态。来源、首发和发布时间的验证标记固定为 false；计算正确不能代替独立证据审核。

现有 outcome 数值字段只能接收有限十进制。helper 把精确同比向零截取为 12 位小数作为 `yoy.value_text`，明确标为派生序列化值；最终类别仍先由精确分数决定，并用既有 `category` 验证序列化值属于同一类别，不一致则拒绝返回。固定三位小数输入与边界之间的非零距离大于截取误差，仍保留运行时核对。不能把 `index_value_text` 填进以百分数为单位的 outcome 字段。

独立审查通过后，操作员才使用既有证据登记、盲化确认及评分流程；`document_sha256` 保存原新闻稿哈希，分别登记二元 `binary.value_text` 与五类别 `yoy.value_text`。在既有 `source_reference` 或其指向的审核记录中绑定原始 URL、Table 1 行列、原始指数、合同标识与计算候选 SHA256，不能把未被登记记录引用的计算文件当成完整溯源。两题属于不同问题版本，可引用同一新闻稿哈希。helper 本身不联网、不写数据库、不选取证据、不评分，不新增控制器或迁移。

合成回归说明：输入 `337.086` 与 `337.087` 的同比都可显示为一位小数 `4.0`，精确类别却分别为 2 和 3。这只是算术夹具，不是尚未发布的 2026 年 11 月结果。

## 6. 生效边界

只有新的完整问题版本、证据、提示词、schema、官方 Terra 配置及预算一起冻结，并在新 DIAGNOSTIC 两题真实通过后，才可进入另外新建 FORMAL 的其余检查。生产网络、TSA 信任及独立入场不由本算术模块满足。必须在截止前取得可验证的 REGISTRATION 和 FORECAST 时间证明，不能追认。

FORMAL 实际成立之后才登记公布后的结算任务或给出绑定真实 ID 的结算命令。当前不声明有自动等待、首发采集、独立裁决或正式成绩。
