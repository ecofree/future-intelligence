# ADR-018：正式入场、接口联调与可部署运行分离

状态：工程采纳；真实服务/生产验收独立。

- 新 LIVE 实验在尝试或批次前固定 FORMAL/DIAGNOSTIC。诊断可验证供应商接口，但不能进入正式批次；旧无政策记录不追溯升级。
- 入场快照与独立审核进入追加式数据库，政策和文档哈希进入预登记承诺。NOT_FOUND 只针对给定快照，不等于证明全网未知。
- 正式资格约束下沉至领取和 provider_requests 写入；不能绕过新 CLI 使用旧调用入口。锁等待后按数据库当前时间检查，预留封存时间；未知调用不自动重发。
- 同一发布族与 UTC 发布时间为 BLS 分簇起点；跨序列不应制造独立样本。人工审核负责实际相关性，旧记录不改写。
- 数据库是真相来源，有界运行器复用原任务/预算/恢复接口；不另建平行控制器。
- Docker 默认只读本机工作台，数据库不发布端口。迁移、裁决、时间验证和模型身份分离，模型/付费联网需显式启用。
- 备份仅新路径，恢复仅随机新库；同集群演练与跨主机生产恢复分开验收。日志告警不冒充通知送达。
- 浏览器必须直接看到 FIXTURE/LIVE、赛制和运行模式；FORMAL 配置不等于正式计分资格。
- 具体代码、失败修复与测试证据以验收报告为准。
