# ADR-019：版本化工程基线、安装包核验与本地预检

日期：2026-11-17。状态：本批采用；生产验收不在本决定中。

## 决定

将内部工程预览固定为 `2.0.1.dev1`，通过普通 merge 收束已有叠加 PR，保留全部历史和 SQL 迁移校验和。主分支合并后核对内容 tree，并以 main 自身检查记录验收。

在 CI 实际构建 wheel，与 git 跟踪的包资源逐字节比较，在新虚拟环境、checkout 外、Python -I 再验安装后的全部资源和 CLI。额外文件、迁移遗漏、版本漂移和源码变动均拒绝通过。这是受信源码的一致性验证，不冒充独立签名、完整依赖锁定或可复现构建。

新增按角色选择的无联网预检，复用现有 secret-file 边界，不自动搜索旧凭证；仅报告配置存在/缺失/不可读，不输出值或路径。配置存在不触发付费请求，也不授权真实验收状态迁移。修复 FIFO 输入在 fstat 前阻塞的边界问题。

## 后果与限制

工程基线可复用，操作人员可以在不调用模型的情况下定位缺失的配置。真实模型身份/usage/费用、独立 TSA、现实结果与目标宿主运行仍需分项验收。此决定不自动发布 PyPI/GitHub Release，不公开研究数据，不更改仓库可见性、许可证或分支保护。
