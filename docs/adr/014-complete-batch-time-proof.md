# ADR-014：完整批次与独立时间证明

状态：工程实现；独立外部服务验收未关闭。

沿用原内容承诺原语，增加 `fi.batch-text.v1`。对数据库封存的精确 UTF-8 记录字节加独立32字节 nonce，进行域分离哈希和 Merkle 聚合；subject 还绑定批次 UUID、类型和记录数。此格式不是 RFC8785/JCS，不能重新序列化记录再声称相同字节。

实验必须有 REGISTRATION 与 FORECAST 两个全量任务批次。前者在任何 attempt 前捕获；后者捕获即关闭新预测写入。失败任务不能从公开可核验分母中消失。

RFC3161 验证由独立数据库登录执行 OpenSSL 链/签名/摘要/nonce 校验，再解析有界 TSTInfo 并核对独立固定的 CA、政策 OID 与时间精度。采用时间上界判定截止。数据库信任隔离的验证器，但导出工具必须重验原始证明，不接受数据库标签作为独立证明。

本批不检查 CRL/OCSP，不提供历史证书长期验证，不把本地测试 CA 当第三方 TSA。OTS 独立保留状态，可选 CLI/Bitcoin 节点验证不替代精确 TSA 时间资格。

完整外部信任验收、生产存储保护和公开授权仍是上线门槛。
