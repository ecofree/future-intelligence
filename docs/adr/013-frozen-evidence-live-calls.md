# ADR-013：冻结证据与可审计的单次供应商调用

日期2026-11-16。状态：实现与数据库契约接受；真实供应商运行待验收。

1. 同实验、同问题只有一个不可替换证据包，必须覆盖全量问题并早于任何attempt。当前是operator提交的材料快照，不冒充自动抓取或可信发布时间。
2. 沿用既有任务/租约/预算/恢复账本。网络调用不持有数据库事务；精确无密钥请求先登记，只有prepare首次返回true允许发送。未知提交结果、失败或超时不自动重发。
3. 三家均用固定官方HTTPS端点、单次文本结构化请求，不提供外部工具或任意参数透传。端点/提示词/输出协议变更需要重新登记实验；模型不静默替换。
4. 既有fixture路径不能伪装LIVE；原有低层SQL入口改名为私有函数，保留最小安全包装，不新增调度控制层。0006以新增迁移修正错误优先级及嵌套JSON约束，旧迁移校验保持不变。
5. 保存最终JSON、简明理由、合法引用、使用量、返回模型标识和原响应字节哈希；**不保存完整原始响应、供应商隐藏思考或可能回显秘密的错误正文**。这收窄原方案的“原始响应引用”要求：可审计最终输出及请求，但无法从哈希独立还原全部响应或证明供应商来源。未来需要独立执行见证时另行设计，不能用目前哈希夸大可信度。
6. 实际计费保持未知直到对账。价目估计供规划/诊断，不用它自动释放预算；缓存折扣和模型特殊计费需实际验证。预算预留不提供外部exactly-once计费保证。
7. 凭证在部署环境注入，CI无真实密钥。测试可向run_once注入合成传输，但生产CLI固定HTTPSOnce；合成结果只用于CI，不导入正式成绩。
8. P0-03实现、真实数据库测试、真实API、外部时间证明四项分别记账。真实API条件缺失不阻碍可独立实现的P0-04代码，但阻止完整MVP验收。
