# ADR-01～ADR-10 · V2.0.1

状态：设计已采纳；各条实现状态见任务清单。不因文档冻结而声称生产已完成。

| 编号 | 决策 | 验收证据 |
|---|---|---|
| ADR-01 | 实验、完整题集与模型任务预登记；任务仅一份初始提交；披露失败与未披露项；私密承诺加随机 nonce | 删除/遗漏/重复正式任务能被批次对账检测；结果后挑版本被拒绝 |
| ADR-02 | TSA 与 OTS 独立状态/attempt；校验失败不等于成功；时间误差和截止资格预登记 | 截止后才获得证明不能倒签；TSA 故障不伪造 VERIFIED |
| ADR-03 | 实验管理、单题评分、统计分析、展示四者逻辑分离，不拆成四个服务 | 所有得分追溯到题目/预测/结果/算法版本 |
| ADR-04 | 样本量依据试点方差与目标效应估计；正式样本计划冻结 | 假设、效应、功效和方差来源可导出；不以固定题量宣称显著 |
| ADR-05 | 预设主比较；其他比较 Holm 调整；探索性结论标记 | 校正前后数值可复核；禁止不显著等同于等效 |
| ADR-06 | 事件簇预登记，同一事件衍生题不能充独立样本；聚类 Bootstrap | 同簇题一起重采样；报告题量与簇量；种子和参数可复现 |
| ADR-07 | 数据源许可作为机器可执行门控，默认拒绝 | 过期/撤销/缺用途授权阻断采集、模型输入和导出 |
| ADR-08 | 外部网页为不可信数据；工具权限和密钥不由网页修改 | 提示注入/SSRF/超大文件测试；无凭据泄漏 |
| ADR-09 | 早期信号登记其时间、预期后果、失效条件和后续观察 | 失败信号和没有触发的信号同样留档；禁止挑成功案例 |
| ADR-10 | 研究价值单独评估，与 Brier/统计显著性不互相替代 | 前瞻研究目标、证据和使用反馈有审计；不以报告长度作质量 |

ADR-09/10 为 P1，首期不因此建设完整机会发现平台。
